# Elite Tour USA — новый сайт

Статический сайт частного гида по США (русскоязычная аудитория). Без бэкенда,
без сборщиков и зависимостей: чистые HTML/CSS/JS, генерируются одним node-скриптом.

```
data/site.json     ← весь текст, цены, программы, FAQ. Правится здесь.
build.mjs          ← генерирует страницы из site.json
site/              ← готовый сайт, его и заливать на хостинг
  index.html
  tury/<slug>/index.html   × 16
  assets/style.css, assets/app.js, assets/img/*.jpg
  sitemap.xml, robots.txt
```

## Пересобрать

```bash
node build.mjs
```

Скрипт печатает предупреждения, если что-то требует внимания (см. «Что доделать»).

## Посмотреть локально

```bash
python3 -m http.server 8412 --directory site
```

Открыть http://localhost:8412

## Что здесь сделано и почему

Решения приняты после разбора старого сайта и совета четырёх моделей
(GPT-5.6 Sol, Gemini 3.1 Pro, Grok 4.5, Kimi K3). Основное:

- **Цены на витрине.** На старом сайте они были спрятаны внутри страниц; восемь
  экскурсий имеют конкретную стоимость — теперь она в карточках, в отдельном
  прайс-листе и в микроразметке. Это главное отличие от прототипа ChatGPT,
  где цен не было вообще.
- **Не «люкс», а конкретика.** Тёмно-синий с золотом и Playfair — дефолтный
  ИИ-шаблон «luxury travel»; для гида с ассортиментом от Диснейленда до
  стрельбища он читается как обёртка без ответственности. Взят документально-
  редакционный язык: выгоревшая бумага, асфальт, терракота, Unbounded + Onest +
  JetBrains Mono, данные (цена / часы / что входит) как основа композиции.
- **WhatsApp-first.** Каждая карточка и каждая страница ведёт в WhatsApp с уже
  подставленным текстом. Форма ничего не отправляет на сервер — она собирает
  сообщение и открывает чат, поэтому заявки не теряются в спаме.
- **Отдельный URL на каждую экскурсию** (`/tury/<slug>/`) с микроразметкой
  `TouristTrip`, плюс `FAQPage` и `TravelAgency` на главной, sitemap и robots.
- **16 услуг разложены по намерению** на пять категорий, а не свалены в
  выпадающее меню на 16 пунктов.
- **Убрано:** Login / Sign Up (регистрация на сайте гида ничего не давала).
  «Продвижение в соцсетях» вынесено из каталога экскурсий в блок «С чем ещё
  помогаю» — в каталоге туров оно разрушало позиционирование.

## Что доделать перед публикацией

**1. Фотографии.** Все изображения на сайте сгенерированы нейросетью
(Nano Banana 2) — это пейзажи и виды, без людей и без узнаваемых лиц.
Они честно работают как атмосферный фон, но:

- `assets/img/guide.jpg` — **нужно настоящее фото Геннадия.** Сейчас на его
  месте заглушка. ИИ-портрет здесь ставить нельзя: человек продаёт себя,
  фальшивое лицо убивает доверие быстрее, чем помогает картинка. Положите файл
  с этим именем и пересоберите — он подставится сам.
- Реальные кадры из поездок заменят сгенерированные в любой момент: просто
  положите свой JPEG под тем же именем в `assets/img/`.

**2. Четыре ответа в FAQ я написал по здравому смыслу, а не взял со старого
сайта.** Их нужно подтвердить или переписать в `data/site.json`:

- «На чём поедем?» — предполагается личный автомобиль гида;
- «Едем с детьми — это нормально?» — про детские кресла;
- «Как оплатить?» — предполагается расчёт на месте без предоплаты;
- «Что если планы поменяются?» — предполагается перенос без штрафа.

Сборка каждый раз о них напоминает. Пока не подтверждены — это обещания от
имени Геннадия, которых он не давал.

**3. Отзывы.** Перенесены четыре штуки со старого сайта: без фото, дат и
маршрутов они слабые. Сильнее всего сработают скриншоты реальной переписки
(с замазанными номерами) или видеоотзывы с YouTube-канала.

**4. Домен и `domain` в `data/site.json`.** Сейчас `https://elitetourusa.com` —
от этого значения считаются canonical, Open Graph и sitemap. Если адрес другой,
поменяйте и пересоберите.

## Публикация

Папка `site/` — обычная статика, кладётся на любой хостинг как есть:
Netlify, Cloudflare Pages, GitHub Pages, или просто в корень текущего сервера
вместо WordPress. Бэкенд, база и PHP не нужны.
